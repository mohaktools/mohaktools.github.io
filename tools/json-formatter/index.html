Frequently Asked Questions

Can I minify JSON?

Yes. Choose Minify JSON to remove formatting whitespace while preserving the JSON data.

Does it validate syntax?

Yes. The formatter parses the input first and displays a syntax error if the JSON is invalid.

Is my JSON uploaded?

No. Formatting runs locally in your browser.
