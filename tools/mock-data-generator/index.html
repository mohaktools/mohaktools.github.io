About the Mock Data Generator

The Mock Data Generator produces realistic fake records for testing: names, emails and addresses, in JSON or CSV. Set how many rows you need and which fields to include.

Mock data lets you build and test a table, a chart or an import without waiting for a real export and without putting anyone's personal data into a development environment. That second point matters legally as well as ethically: test data built from real customers carries the same obligations as production data.

The records are generated, so they are not real people. Do not treat a generated email as deliverable or a generated phone number as dialable; some will collide with real ones by chance.

Frequently Asked Questions

Is the generated data real?

No. It is randomly generated for testing, though a name or number may coincidentally match a real one.

Which fields can I generate?

Names, emails and addresses, selected per record. The output can be JSON or CSV.

Why use mock data instead of a real export?

It avoids putting personal data into test environments, and it is faster than anonymising a real dataset.

Can I use it for load testing?

Small volumes, yes. For large-scale tests generate the data in code so it can be reproduced and seeded.

Is it safe to email the generated addresses?

No. They are not real mailboxes, and some will belong to real people by chance.

Does it generate Indian names?

The pool is international. Check the output before using it in a demo that needs to look locally realistic.
