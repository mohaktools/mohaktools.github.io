About the Number to Words

Number to Words writes a figure out in full, in either the Indian or the international numbering system. Enter a number, choose the format, and it returns the name of that number, which is what you need when writing a cheque, filling a legal document, or checking that a figure was read correctly.

The two systems group digits differently. The international system uses groups of three, so 1,000,000 is one million. The Indian system uses a group of three followed by groups of two, so the same figure is ten lakh, and 10,000,000 is one crore. Choosing the wrong one produces text that is correct in English but wrong for the document in front of you.

Decimal parts are handled as paise or cents depending on the format, and the output is plain words without currency symbols. For a cheque, write the words and then draw a line through the remaining space so nothing can be added afterwards.

Frequently Asked Questions

What is the difference between Indian and international formats?

The Indian system groups digits as thousands, lakhs and crores; the international one uses thousands, millions and billions.

Can it handle decimals?

Yes. The fractional part is read out as paise in the Indian format and as cents in the international one.

How large a number can I convert?

Up to crores and billions comfortably. Extremely large figures may lose precision because JavaScript stores numbers as floating point.

Does it add the word rupees?

No, it returns the number in words only, so you can use it for any currency or none.

Can it convert negative numbers?

Negative values are read with a minus in words, which suits accounting notes but not cheques.

Why does my cheque use lakh when the bank writes million?

Indian banks use the Indian system, so ten lakh is correct there even though the same figure is one million internationally.
