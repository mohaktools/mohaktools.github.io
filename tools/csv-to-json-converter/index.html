About the CSV to JSON Converter

The CSV to JSON Converter turns a comma-separated table into an array of JSON objects. The first row is read as the field names, and every row after it becomes one object.

It handles the parts of CSV that trip up a naive split: fields wrapped in double quotes can contain the delimiter, and a doubled quote inside a quoted field is read as one literal quote. Commas, tabs, semicolons and pipes are all available as the delimiter, since exported files from Excel, databases and regional settings do not always use commas.

Numeric-looking values are converted to numbers, so 30 becomes 30 rather than "30", which is usually what you want for an API payload. The result is flat: nested structures need a different tool.

Frequently Asked Questions

How are the field names decided?

The first row is used as headers and becomes the object keys. Leading and trailing spaces in each header are trimmed.

What if a field contains a comma?

Wrap it in double quotes. The parser keeps quoted delimiters inside the value.

Are numbers converted to numbers?

Yes, numeric-looking values become JSON numbers. Everything else stays a string.

Can it produce nested JSON?

No. Each row becomes a flat object, one level deep.

Which delimiters are supported?

Comma, tab, semicolon and pipe, which covers most spreadsheet and database exports.

What happens if a row is short?

Missing columns come through as empty values rather than shifting the other fields.
