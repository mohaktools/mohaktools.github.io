About the Image to PDF

The Image to PDF tool combines one or more images into a single PDF file. Select the images, choose a page size, and it builds the document in the order you added them.

This is the quick way to turn phone photos of documents into something that can be emailed, printed or uploaded to a portal that only accepts PDF. The images are placed on the page rather than recompressed aggressively, so the output is usually clearer than a screenshot pasted into a word processor.

Keep an eye on file size. Photographs at full resolution can produce a very large PDF; resizing them to the page size first is the simplest way to keep it manageable.

Frequently Asked Questions

Can I combine several images into one PDF?

Yes, select multiple files and they are placed in the order chosen.

Which image formats work?

PNG, JPG and WebP, which covers phone photos and screenshots.

Can I choose the page size?

Yes, A4 and Letter are available so the images fit standard printing.

Will the images be searchable?

No. A PDF of images contains no text layer, so nothing in it can be searched or selected.

Is my data uploaded?

No. The PDF is assembled in the browser, so the images stay on your device.

Why is my PDF so large?

Full-resolution photos. Resize them before adding, or compress the PDF afterwards.
