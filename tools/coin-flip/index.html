About the Coin Flip

The Coin Flip tosses a virtual coin using the browser's random number generator. Flip once for a simple heads or tails, or set a number of flips to see the totals and the ratio between them.

Each flip is independent and has no memory, so a run of five heads does not make tails more likely on the next toss. That misconception, the gambler's fallacy, is exactly what a large number of flips demonstrates: the ratio drifts towards 50:50 not because the coin corrects itself, but because early imbalance gets diluted.

For settling a decision it is as fair as the browser's randomness. It is not cryptographically secure, so do not use it for anything that needs to be unpredictable to an adversary, such as generating a key or a password.

Frequently Asked Questions

Is the flip really random?

It uses the browser's Math.random, which is fine for games and decisions but not cryptographically secure.

Does a previous result affect the next flip?

No. Every flip is independent, so the odds stay 50:50 regardless of what came before.

Can I flip many times at once?

Yes. Set the number of flips and the page shows heads, tails and the ratio.

Why does the ratio not come out exactly 50:50?

Random variation. The gap narrows as a proportion as the number of flips grows, but rarely lands exactly even.

Can I use this to generate a password?

No. Math.random is not secure enough for secrets. Use a cryptographic generator.

Does it work offline?

Yes, the flip happens entirely in the page.
