About the To-Do List

The To-Do List keeps your tasks in order with a priority attached to each. Add a task, set how urgent it is, tick it off when it is done.

A flat list with priorities beats a complicated system you stop using. The point of marking priority is to make the next action obvious: when you open the list, the top item should be the one worth doing first.

Tasks are saved in your browser's local storage on this device. There is no account and no sync, so clearing site data or switching devices starts an empty list. For anything you cannot afford to lose, keep a copy elsewhere.

Frequently Asked Questions

Where are my tasks saved?

In your browser's local storage on this device. Nothing is uploaded.

Do tasks sync across devices?

No. Local storage is per browser and per device.

How does priority work?

Each task carries a priority and the list can be sorted by it, so urgent items stay at the top.

Can I edit a task?

You can remove and re-add it. Editing in place is not supported.

What if I clear my browser data?

The list is deleted. There is no backup.

Is there a limit on how many tasks?

No hard limit, but a very long list defeats the purpose. Keep it to what you will actually do.
