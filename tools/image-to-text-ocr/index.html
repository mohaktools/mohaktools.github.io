About this OCR tool

Text recognition runs in your browser using Tesseract.js. The OCR engine and selected language data are downloaded from a CDN the first time you use them; your image itself is processed locally. Clear, well-lit images with straight text usually produce the best results. OCR does not preserve page layout, tables, or fonts.

Frequently asked questions

Which image types can I use?

Use common image formats such as JPG, PNG, WebP, or BMP. The file must be 20 MB or smaller.

Does the image leave my device?

The image is processed locally in your browser. The OCR engine and language model may be downloaded from a CDN; the image is not uploaded to MohakTools.

Why does the first extraction take longer?

The OCR library and language data need to load before recognition starts. Later use may be faster because the browser can cache those files.

How can I improve the result?

Use a sharp, evenly lit image, keep the text upright, and choose the correct language. The contrast option can help with pale or low-contrast print.

Can I edit or save the extracted text?

Yes. Edit the result directly, copy it to your clipboard, or download it as a plain text file.
