About the PDF Merge / Split

The PDF Merge and Split tool combines several PDFs into one document, or pulls a page range out of a single file into a new PDF.

Merging is the common job: joining a signed form to its annexures, or assembling a report from sections exported separately. Splitting is the reverse, and the useful case is extracting a few pages, such as the ones a client actually needs, without sending the whole file.

Everything happens in the browser, which matters for contracts and identity documents that should not be uploaded to an unknown server. Page order is preserved for merges, and the page range syntax accepts entries like 1-3, 5.

Frequently Asked Questions

Can I merge more than two PDFs?

Yes, select as many as you need and they are joined in the order chosen.

How do I specify pages to extract?

Use a range such as 1-3, 5, which takes pages one to three plus page five.

Is the page order preserved?

Yes for merges. Files are appended in the order you selected them.

Are my files uploaded?

No. The work is done locally with pdf-lib, so the documents stay on your device.

Does it keep bookmarks and forms?

Basic page content is preserved. Interactive forms, bookmarks and signatures may not survive a merge.

Can it split every page into a separate file?

Extract the range you need per file. For one file per page, repeat with each page number.
