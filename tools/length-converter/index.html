Yard (yd) Used for fabric, sports fields and distances.
Mile (mi) Used for road distances in several countries.
Nautical Mile (nmi) Used in marine navigation and aviation.

Common Length Conversions

These are useful reference values for everyday calculations.

How many centimetres are in one metre?

One metre equals 100 centimetres.

How many metres are in one kilometre?

One kilometre equals 1,000 metres.

How many centimetres are in one inch?

One inch equals exactly 2.54 centimetres.

How many feet are in one metre?

One metre is approximately 3.28084 feet.

How many kilometres are in one mile?

One international mile equals exactly 1.609344 kilometres.
