About the Morse Code Translator

The Morse Code Translator converts ordinary text into Morse code and back again. Type letters, numbers and punctuation, and it returns the dots and dashes; paste Morse in and it decodes it to text.

Letters are separated by a space and words by a slash, which is the convention that keeps the output readable. Each character maps to a fixed pattern: A is dot-dash, B is dash-dot-dot-dot, and so on, with digits using five symbols each. The mapping is the international standard, so anything you generate here can be read by any Morse reference.

Morse is no longer required for maritime distress, that role ended in 1999, but it survives in amateur radio, aviation beacons and as a puzzle format. If you are learning it, the rhythm matters more than the visual pattern: the gaps between letters and words are what make a transmission readable.

Frequently Asked Questions

How are letters and words separated?

A single space separates letters and a slash separates words, which is the standard written convention.

Does it support numbers?

Yes, all ten digits have five-symbol codes, and common punctuation is included too.

Can I decode Morse back to text?

Yes, paste the dots and dashes and the tool converts them to letters, as long as the letter and word separators are present.

Is Morse code case sensitive?

No. Uppercase and lowercase letters map to the same pattern.

Is Morse code still used?

Not for commercial distress signals since 1999, but it remains in amateur radio, navigation beacons and puzzles.

What if my Morse has no spaces?

It cannot be decoded reliably. Without separators the boundaries between letters are ambiguous.
