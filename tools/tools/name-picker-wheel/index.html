About the Name Picker / Wheel Spinner

The Name Picker spins a wheel to choose one name from a list at random. Paste your entries, one per line, press spin, and the wheel stops on a winner.

It is the digital version of drawing lots: a fair way to pick a winner for a quiz, assign a task, or settle who goes first. The pick is uniform, so every name has the same chance on every spin, regardless of where it sits on the wheel.

For a public draw, keep a record: the list you used, the number of entries and the result. A random pick is only convincing if the process behind it can be shown to have been fair.

Frequently Asked Questions

Is the pick fair?

Each name has an equal chance on every spin, using the browser's random number generator.

How should I enter the names?

One per line. Blank lines are ignored.

Does the position on the wheel affect the odds?

No. The winner is chosen randomly; the spin is only the animation.

Can I remove a winner after the spin?

Edit the list and spin again. There is no automatic elimination, so delete the name yourself for a knockout draw.

Is there a limit on how many names?

A few dozen is comfortable. Far more than that and the labels become unreadable on the wheel.

Can I save the result?

Take a screenshot, or note it down. Nothing is stored after you close the page.
