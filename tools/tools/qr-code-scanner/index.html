About the QR Code Scanner

The QR Code Scanner reads a QR code from an uploaded image and shows the text inside it, whether that is a link, a message, contact details or Wi-Fi credentials.

Decoding is done by jsQR, a JavaScript library that locates the three corner squares of the code, corrects for perspective and reads the data. That is why a photo taken at an angle usually still works: the library straightens it first.

A QR code is just text in a square. That is worth remembering before scanning an unknown one: the code cannot install anything, but the link inside it can lead anywhere. Read the decoded text here before you open it.

Frequently Asked Questions

How does it read a QR code?

It locates the position markers, corrects for angle, then decodes the pattern into text.

Does it work with a photo at an angle?

Usually yes, up to a point. Straight-on, well-lit images decode most reliably.

Can I use my camera?

This page reads an uploaded image. For live camera scanning, use your phone's camera app.

Is the image uploaded?

No. Decoding happens in the browser.

Why does my code not decode?

Blur, glare, low contrast or too little of the code in frame. A larger, sharper image usually fixes it.

Is it safe to open the decoded link?

Only if you trust the source. The code itself is harmless; the destination may not be.
