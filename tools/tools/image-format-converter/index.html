About the Image Format Converter

The Image Format Converter rewrites an image as PNG, JPG or WebP. Load a file, pick the target format and, for JPG and WebP, the quality, then download the result.

The format changes what the file can do as well as how big it is. PNG is lossless and supports transparency, so it suits logos, screenshots and anything with sharp edges or text. JPG is lossy and has no transparency, but compresses photographs very well. WebP usually beats both for photographs at the same visual quality and is now supported by every current browser.

Quality only applies to the lossy formats. At 80 per cent most photographs are visually indistinguishable from the original at a fraction of the size; below about 60 per cent banding and blockiness start to show, especially in gradients and skies.

Frequently Asked Questions

Which format should I choose?

PNG for logos, screenshots and anything needing transparency. JPG for photographs where size matters. WebP for the best size at good quality on the web.

Does converting to JPG lose quality?

Yes, JPG is lossy. Each save discards a little detail, so avoid repeated conversions.

What quality setting should I use?

Around 80 per cent for photographs. Lower values shrink the file further at the cost of visible artefacts.

Can I keep transparency?

Only with PNG or WebP. JPG has no alpha channel, so transparent areas become white.

Why did my GIF become a still image?

The conversion produces a single frame. Animation is not carried across.

Is the image uploaded?

No, the conversion happens in your browser.
