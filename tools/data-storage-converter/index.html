Understanding data storage units

Learn the difference between common data units and how conversions work.

Bits and bytes

A bit is the smallest basic unit of digital information. A byte consists of 8 bits and is commonly used to measure file sizes.

1 byte (B) = 8 bits (b)

Decimal units: KB, MB, GB

Decimal units use powers of 1,000. They are commonly used for drive capacity and data transfer specifications.

1 GB = 1,000 MB

Binary units: KiB, MiB, GiB

Binary units use powers of 1,024. They are useful when working with binary-based memory and computing measurements.

1 GiB = 1,024 MiB

Bits per second vs. bytes

Network speeds are commonly measured in bits per second, while file sizes are usually measured in bytes. These measure different things: transfer rate versus stored data.

8 megabits = 1 megabyte

Frequently asked questions

What is the difference between KB and KiB?

A kilobyte (KB) uses the decimal standard and equals 1,000 bytes. A kibibyte (KiB) uses the binary standard and equals 1,024 bytes.

How many megabytes are in one gigabyte?

One decimal gigabyte equals 1,000 megabytes. One gibibyte equals 1,024 mebibytes. Always check which unit standard is being used.

How many bits are in a byte?

A byte consists of 8 bits.

Why does my drive show less capacity than advertised?

Drive manufacturers commonly use decimal units, where 1 GB is 1,000,000,000 bytes. Some operating systems display capacity using binary-sized values while labelling them with decimal-style names. Formatting and system partitions can also affect available space.

What is the largest unit supported?

This converter supports decimal exabytes (EB) and binary exbibytes (EiB), alongside smaller units.
