About the Internet Speed Test

The Internet Speed Test measures your download speed, latency and how much data was transferred during the run. Press start and it fetches a file repeatedly, timing how long the transfer takes.

Latency, or ping, is the round-trip time for a tiny request. It matters more than raw speed for video calls and online games: a 200 ms ping makes conversation feel delayed even on a fast connection. Download speed decides how quickly pages, videos and updates arrive.

Browser-based tests are indicative rather than exact. They measure what one browser tab can pull from a particular server, so the result reflects the whole path: your device, Wi-Fi, the local network and the route to that server. For a figure to compare with your ISP's claim, use a wired connection and stop other downloads first.

Frequently Asked Questions

What do download speed and ping measure?

Download speed is how fast data arrives; ping is the round-trip delay for a small request, which affects responsiveness.

Why is my result lower than my plan?

Wi-Fi, distance from the router, other devices, the test server and browser limits all reduce the figure. Try a wired connection.

Is upload speed measured?

The main measurement is download. Upload tests need a server that accepts a large body, which a public CDN does not.

How accurate is a browser speed test?

Good enough to spot a problem, not a substitute for a proper measurement tool.

Why does ping matter more than speed for calls?

Because calls are real-time. High latency causes lag and overlap; bandwidth beyond a few Mbps adds little.

Does it use my data plan?

Yes. A test transfers several megabytes, so on mobile data it consumes some.
