About the Color Palette Generator

A palette is a small set of colours that work together. This generator starts from one base colour and derives the rest using the colour wheel. Complementary palettes use the colour opposite the base for strong contrast. Analogous palettes use neighbouring hues for a calm, unified look. Triadic palettes use three colours spaced evenly around the wheel for a vivid balance. Shades vary the lightness of one colour from pale to deep, which is useful for backgrounds and UI states.

Every swatch shows its HEX code, and clicking it copies the code to your clipboard. All calculations run in your browser.

Common questions about Color Palette Generator

What is a complementary colour?

The colour directly opposite the base on the colour wheel, 180 degrees away in hue.

Can I use the palette in my website?

Yes. Copy the HEX codes into your CSS. Check text contrast before you use them for body text.

Why does my palette look different from the base colour?

Palettes include derived hues and lightness steps, so the base is one of several colours rather than an exact match for every swatch.
